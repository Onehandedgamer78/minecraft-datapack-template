# Publishing standards

**AI GENERATED — documentation generated using OpenAI ChatGPT/Codex.**

Requirements set by Ethan Kiefer on November 9, 2026:

- Each independently useful datapack gets a separate public GitHub repository, source history, and installable ZIP.
- Other people must be able to use an integration without Ethan's full modpack. Document required dependencies precisely.
- Use **AI GENERATED** in the repository description, README notice, in-game datapack description, release title, release notes, and included AI_DISCLOSURE.md.
- Suggested ZIP name: PROJECT-ai-generated-VERSION.zip.
- Record exact supported versions and distinguish intended compatibility from compatibility actually tested.
- Include installation instructions, changelog, known limitations, credits, license, and validation results.
- Put pack.mcmeta and data/ at the root of an actual release ZIP. Include README.md, AI_DISCLOSURE.md, LICENSE, and applicable third-party notices.
- Choose metadata schema and pack format only after confirming the target Minecraft version.
- Keep additional biome-mod integrations in separate repositories. Keep optional Pokémon spawn changes independently installable where practical.
- Mark work EXPERIMENTAL / UNTESTED IN GAME until relevant generation and spawning have been checked.
- Apply AI labels to our generated contributions accurately. Preserve upstream authorship.
